# Leave One Light On — Website V3 Review Notes

Branch: `website-v3`

## Purpose

Move LeaveOneLightOn.org from book-first presentation to movement-first institutional identity while preserving the origin story and keeping The Light in the Window as the book/story property.

## Locked identity

- Movement: **Leave One Light On**
- Action/support language: **Keep the Light On**
- Book: **The Light in the Window**
- Tagline: **A Movement of Hope and Practical Compassion**

## V3 changes in this branch

- Reworked homepage around Leave One Light On as the primary identity.
- Added restrained metallic-gold treatment and shimmer for signature uses of LIGHT.
- Added reduced-motion support in the visual system.
- Repositioned The Light in the Window as the story behind the movement and linked to the independent WordPress book site.
- Rebuilt Keep the Light On as an action invitation rather than a competing movement name.
- Replaced under-construction Story, House, and Gormans pages with concise movement-aligned content.
- Standardized navigation/footer identity on upgraded pages.
- Added truthful pre-formation organizational-status language without claiming current 501(c)(3) recognition.
